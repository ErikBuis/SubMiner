type: added
area: anki

- Added `ankiConnect.behavior.widenSentenceToTranslation`: when one secondary line translates several primary lines, the card sentence and its media widen to all of them (capped by `media.maxMediaDuration`). Off by default.
- Added `ankiConnect.behavior.formatTranslation`: card translations start with a capital letter and a trailing comma becomes a period. Off by default.
